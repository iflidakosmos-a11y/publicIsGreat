豆腐烘蛋
+
做法
1.簡單版做法-- 板豆腐壓成泥，拌入蛋液青蔥薑碎+調味料:鹽糖白胡椒粉或香料粉，入油鍋煎成型，食用前加一點芝麻油或芝麻粉 2.蔬菜版做法-- 大致與1相同，需留意的點：加入的蔬菜或菇類都要切小丁容易煮熟，食材味道不要太強烈免得彼此不融合 我前幾天做的豆腐煎餅（圖），加了高麗菜金針菇紅蘿蔔，因為食材多而手邊的蛋不夠，就加了一些麵粉太白粉幫助它定型
預製保存問題回覆（亭吟提問）
從你貼的照片來看，在拌食材時就水分太多，需要把板豆腐的水分壓乾一點，比較好成形。 1️⃣因包含各種食材(彼此產生化學變化易變質），預先拌好的豆腐蛋泥冷藏兩天內是最適宜的。 2️⃣如果想冷藏三天以上，食材要分開存放:豆腐和蛋拌勻、料切好，要下鍋前合併及調味。 3️⃣全部煎起來的做法也是選項，但以冷藏三天內食用完為最佳。
滷牛腱
+
整顆的滷牛腱也是方便營養的常備菜之一 作法： 1️⃣滷汁：滷包都是自己買中藥材來包，滷汁裡加薑片鹽米酒少許醬油冰糖。材料-川芎、桂枝、八角、花椒、甘草、月桂葉。當然市售滷包也行。 2️⃣牛腱前置處理：我喜歡牛腱肉裡筋紋多的QQ感，都是買澳洲小花腱。牛腱要先川燙掉血水，川燙水裡加薑片蔥段米酒，冷水入鍋，小火把血水煮出來後洗淨牛腱割除表面筋膜後入滷鍋 3️⃣滷製：滷牛腱最主要的過程是浸泡，先大火煮滾3分鐘轉小火煮10分鐘加蓋熄火浸泡放涼，我一般會反覆煮開➡放涼➡煮開➡放涼的過程3～4次 4️⃣泡在滷汁裡放涼後取出分裝冷凍，想吃時拿一顆出來冷藏退冰，隔天切片加上青蔥香油醬汁作為配菜
補充
1. 怎麼知道是否滷透了？ 拿一根筷子插牛腱看看是否可穿透 2. 滷牛腱以冷食為主，不建議加熱後切片。如果不喜冷感，可放至退到室溫再食用
羅宋湯
+
羅宋湯適合重複加熱，使用的食材都是耐燉煮的，湯頭略帶酸味，可以因地制宜選用手邊現有的食材～ 原則上的食材內容如下： 1.肉燉湯＋ 2.炒過的洋蔥紅蘿蔔新鮮蕃茄蕃茄泥+ 3.根莖類/芹菜/大蒜+ 4.高麗菜之類耐燉煮的蔬菜菇類可 5.調味-鹽/胡椒/酸奶油(可用其他酸味的食材取代譬如希臘優格檸檬）
雞湯（先煎版）
+
生雞腿先抹鹽，醃一下讓牠出水， 下鍋前擦乾水分，乾鍋煎香帶皮的那面，起鍋備用。 用鍋裡煎出來的雞油爆香蔥薑，下雞腿肉加米酒炒一下，加水大火煮開撈浮沫幾回，轉小火燜煮至熟透，起鍋前調味。 P.S. 有時候我受不了雞肉的雞味，就會用鹽醃、先煎過的方式轉化它，同時增加雞湯的香氣。

+

熬蝦湯
+
做法
熬蝦湯-- 我把薑碎片下油鍋爆香，再下蝦殼，下一點米酒，炒香後加熱水蓋過蝦殼，熬至水剩一半熄火。放涼後冰起來。
5/17課後補充說明
🍲「熬蝦湯」 請加註：熬至水剩一半，熄火放涼，瀝掉蝦殼後冰起來備用。
補充說明
感覺蝦殼沒有炒乾炒香，熬出來的蝦湯沒有蝦紅素(蝦湯會浮一層紅色的油）
義式水煮魚
+
流程（回覆純瑜提問）
把流程寫一下： 魚先醃過，擦乾後下油鍋，放側邊就可以下洋蔥絲炒，魚單面煎香後翻面，繼續炒洋蔥。火力保持中火，洋蔥炒好，魚也差不多煎好，下白酒嗆鍋(白葡萄酒或米酒），再加蛤仔湯/蕃茄／胡椒粉，加蓋悶煮一會兒，等魚吸收後下新鮮蛤仔/洋香菜加蓋等蛤仔開口，調味，起鍋。
回覆純瑜問洋蔥做法
油炒，炒出焦糖化。 原本是一鍋到底，當日因鍋子比較小，而分開炒 是！（確認是同一鍋煎魚旁邊炒洋蔥）
紅燒草魚
+
你買的草魚應該是養殖的，難免土腥味，我若買到這種魚，會先做排掉魚肉裡味道的前置作業：在鹽水裡洗淨魚，擦乾，整條魚抹上鹽，放冰箱冷藏靜置讓牠出水，隔天拿出來擦乾水分再下鍋。 草魚適合做紅燒的，可以蓋過牠的腥味。 做法： 草魚煎香撈起，爆香蔥薑蒜豆瓣醬，加一點水，放入草魚，煮滾後放醬油酒糖胡椒粉做調味，燜煮至收汁，起鍋前淋一點香油。
豆豉炒肉片豆乾
+
豆豉炒肉片豆乾-- 不確定你炒製的流程有哪些，通常不好吃多半問題出在豆干。 通常買回來我會要先鹽水川燙，去掉豆腥味以便下鍋時更容易吸附調味。 按照你的食材我重做的話流程-- 1️⃣川燙豆干取出備用2️⃣炒醃肉(炒乾炒香)3️⃣下豆豉(或蔥薑蒜自由配)炒香4️⃣下一點水煮開放入豆干拌勻燜煮至水收乾5️⃣起鍋前最後調味(鹽or香油）
回覆醃肉做法問題
醃肉的部分蠔油+醬油+胡椒就夠了，豆鼓要下鍋去炒（豆鼓醃製時所產生的特有氣味經過翻炒會轉化成另一種美味）
甜筍清炒
+
既然是甜筍，清炒最好吃，用豆瓣醬反而可惜了他自帶鮮美味。 甜筍切絲， 下油鍋爆香蒜頭或薑片（油要多一點） 放入筍，炒香，調味。 p.s.也可以打幾顆蛋下去一起拌炒，增加蛋白質

醋飯（壽司飯）
+

食材索引
只收錄家騏說過的食材知識
🐟 鮭魚
鮭魚算是容易熟的食材，不必先煮熟再冷凍， 可以用你喜歡的口味先醃漬後冷凍，食用前一天拿到冷藏退冰。 煎或烤之前擦乾再入鍋，當餐現料理比較可以吃到魚的風味，而且所費時間也不多。
煮熟的鮭魚的復熱方式，冷藏解凍後我會用電鍋保溫的方式來復熱(電鍋先放30cc水按下跳起後放入在保溫狀態約半小時），而不會再蒸過，這樣可以保持魚肉的口感及風味接近你煮好時的狀態。
🦐 蝦
蝦子螃蟹之類容易腐敗的海鮮，確實先煮熟再冷凍可以保鮮，但食用方式是先放冷藏解凍，再放室溫退冰，並不適合再加熱，再次加熱常會讓風味流失肉質口感改變。 另外，蝦子中間黑黑的一條，有沒有可能是蝦子的腸泥腺，建議在生的時候先去掉再料理會比較好。
如果是整隻帶殻未處理的蝦、小卷之類的海鮮，分裝時會加入蓋過食材的水量再冷凍，用意是比較不會有凍傷。
🍄 菇類
現在菇類都是太空包栽培，一般都算乾淨不用清洗。 當次料理用不完的部分，可以先切成之後料理需要的尺寸，譬如切塊切片切絲，裝袋冷凍。 下次料理前直接拿出來下鍋就行
有包裝的菇類通常不用水洗，沒用完的切成下次烹煮要用的大小放冷凍，下次要用拿出來直接下鍋
🌱 蓮藕 / 山藥
蓮藕、山藥，也很適合作為常備菜，買回來洗淨切片或切塊裝袋冷凍，料理前拿出來退冰即可下鍋，他們雖然是植物但不會因為冷凍改變口感。 這兩個食材都是可涼拌、可炒菜、可燉煮，很好運用。
山藥需要去皮。 蓮藕則依照你買到的狀態，如果是已經刷乾淨的，不用削皮。但如果是帶泥的，刷洗乾淨還是看起來髒髒的，就削皮。
🟡 板豆腐
板豆腐壓成泥，拌入蛋液青蔥薑碎+調味料...入油鍋煎成型（板豆腐的水分壓乾一點，比較好成形） 豆腐的豆味可以透過「過水」或「先煎過」來去除
🍗 雞腿肉
雞腿先川燙再冷凍：這個做法比較適合燉煮用，如果是要煎或其他料理方式，建議生的直接冷凍。
（抹鹽出水時間）看肉的厚度，大概20～30分鐘，記得擦乾。
🥩 豬軟骨 / 豬腹排
豬軟骨、豬腹排，雞肉塊，通常買回來後會先川燙去血水放涼，留下當次要料理的量，其餘裝袋冷凍，可放1～1.5個月。但如果你想要直接醃也行，只是這樣子冷凍保存兩週內為佳。 豬軟骨、豬腹排這類肉類因烹煮至可食用需要較長時間，我通常先料理好再分裝冷凍。
🎋 竹筍
竹筍算是偏涼性的食材， 熱性體質的人吃寒涼的食物沒事，但寒性體質的人遇到像竹筍這類偏涼性的食材，就需採取改變它的性的料理方式，譬如：炒的料理方式 煮湯是竹筍很好吃的料理方式，對身體偏寒的人來說，吃了可能會造成身體負擔
4-5月盛產期是品嚐春季限定「桂竹筍」的最佳時機， 這時期的桂竹筍肉質鮮嫩中帶硬，適合滷、炒、燉湯。
🥒 小黃瓜
今天我也是受不了佛手瓜的涼性，又想吸收他的營養，剛好現在是嫩薑的季節，就切了許多嫩薑和鮮香菇一起炒，吃起來身體反應很舒服。
林純瑜分享：把薑先炒過+木耳，最後小黃瓜拌一下，蓋鍋蓋悶，起來再加點香油，吃起來舒服很多，同時又保有小黃瓜的脆度。（家騏未另作補充）
🥬 葉菜類
蔬菜洗過再冰：這方式雖然方便可立即下鍋但因有水氣容易腐敗，建議蔬菜買回來只洗三天內要煮的量，其他不要洗，用紙巾包起來放塑膠袋冷藏保存會更久。 蔬菜類的保存重點在「不要洗＋減少水氣」，因此如果是容易爛的葉菜類，我會用廚房紙巾包起來放塑膠袋再冰，這樣子保存一週左右，即使葉子有點痿凋，再泡水一下子便會恢復生機。（有時候會用溫水泡，幫助葉子吸水）
🍚 白飯 / 米
（冷凍白飯）我通常不退冰，直接電鍋蒸，可以吃到像剛煮好的熱飯。
防止米生蟲的方式： 1. 冷藏/冷凍：不提供適合的溫度濕度就會讓蟲卵孵化，也可保鮮 2. 米𥚃放辛香料讓蟲蟲不愛靠近，我會放家𥚃做菜會用到的：八角、花椒、辣椒乾、九層塔乾等 3. 少量購買，不屯積
🌿 子薑
子薑有春天尾巴鮮嫩的滋味，帶點初夏熱度的微辛辣。 單吃，或與其他食材涼拌、炒或滷，滿口都是春末初夏的味道。

鹽麴是什麼，為什麼用它
+
鹽麴是由麴、鹽、糖、水發酵而來，能替代鹽、醬油、味素，我看中它的好處，想介紹給大家使用。 它的鹽含量比一般食鹽少，可控制鹽份攝取；其中含有酵素、益生菌、B群等營養成分，能分解蛋白質及澱粉，有助調整腸胃菌種。 涼拌的料理方式最能保留鹽麴的益生菌和酵素活性，所以推薦給大家。
是，味噌的鹽份比較高，耐保存... 哈哈哈...是啊，發酵品含有的益生菌，有的耐熱有的不耐熱，多去嚐試找到自己需要的就對了
鹽麴醃肉注意事項（回覆童淑寬）
+
鹽麴醃，主要是藉鹽麴裡的酵素催化蛋白質，如醃太久，肉質變太軟而出水更易煎焦，且因鹽麴含糖分，直接下鍋煎時沒有控制好火候很容易產生梅納反應。 ✤有幾個方法可減少用爐火煎的梅納反應： 1.下鍋前確實擦乾鹽麴，可減少大部份煎焦的情況 2.鍋裡鋪烘焙紙，減少直接受熱及沾鍋 3.油量夠+低溫慢煎+加鍋蓋半煎蒸 4.確認肉已熟，在最後加大火力上色 ✤使用瓦斯爐火力調整不易，推薦用烤箱/氣炸鍋，方法差不多，好處是不容易焦 ✤鹽麴醃，最省力的料理方式：蒸/煮

料理觀念
家騏說的飲食哲學，原話呈現
這個群組/課程的目的
+
分享我做常備菜經驗是： 爲了縮短大家每日備餐時間，又可以吃到必須的營養。 而在成長上， 建立覺知到自己身體真實狀態的資料庫、 親密身體飲食上的需要、 建立了解各種食材補養自己身體需要的資料庫。 進一步的，藉由飲食覺知到自己的原生意識和無明慣性。
我想與大家分享一個核心觀念：每月一次的實體課學習雖然深刻，但真正的進步其實發生在「每日自己的備餐過程」中。 實體課是引導，而真正的學習是在您自家的廚房裡。因此，我們更鼓勵大家善用群組互動，在日常備餐中遇到任何想改善的細節、或想請教的技巧，請直接在群組裡和我互動。這種「教練式陪伴」的即時交流，才是這門課最珍貴的資源。
因此善用這群組提問，會比實體課更即時，也是最有效的學習
對準身體的需要
+
對準身體的需要，需要多方嚐試，每個人身體回應訊號方式不盡相同。有時候是頭腦走在前面的訊息，最接近的方式是直接去找來吃一點點，看當下身體的反應。想吃大朵香菇就去找來吃看看啊，不一定要全套香菇雞湯要準備到位才能試😉
親密食材
+
我之所以詢問大家那兩個問題，是想了解大家是怎麼和食材建立親密關係的。 所謂「親密食材」，是指帶著覺察、帶著感受去接觸它——當我們在市場相中它、買了它，帶回家後處理它（烹煮或冷藏冷凍），那一連串的過程，都在呈現我們親密自己、親密食材的狀態。而這個過程本身，已經開始在和食物建立關係、吸收它的能量了，有發現嗎？ 或許有人會問：為什麼要親密食材，按照完美的SOP去料理不就好了？ 其實食材從你買下來到成為食物，不是吃進身體才成為養份。而是在你接觸它、感覺它的時候，那個能量交換就已經在發生了。當你真的感受到這個食材，你自然會知道它適合怎麼保存、怎麼烹調，什麼方式對它好，也對你好。完美的SOP固然方便，但不見得適合所有人，也不見得適合當下的你，不是嗎？😉 下次採買時，試著感覺一下自己身體需要什麼，也感覺你手裡挑中的食材，它的重量、溫度、氣味，看看你會不會多一點靈感。
「親密」，不只是貼近自己哦！
備餐也是靜心
+
如果你是有實驗精神的人，可以自己玩看看～ 同樣的食材、同樣的料理工序，不同天自己狀態不同時，做同一道菜的風味和能量會不一樣...。 這樣子你就會知道，要做出美味又滋養自己的食物，很關鍵的條件，做菜的人的靜心品質。而且，因為有了這層瞭解，備餐也能成為一種靜心。 我常在伏案工作一段時間需要站起來動一動時，會走去廚房做點事，有時是拿出下一餐要做的食材感覺他、有時是洗/挑/切菜、有時是打蛋醃肉....等等小事，透過工作靜心重新把自己調焦回來。 當然，工作靜心的面向很多，你找自己有感覺的事物去試。

食材的寒熱屬性
+
之前曾提過要攝取什麼食物要去感知自己身體的狀況和需要，其中一個面向就是燥熱or寒涼 竹筍算是偏涼性的食材， 熱性體質的人吃寒涼的食物沒事，但寒性體質的人遇到像竹筍這類偏涼性的食材，就需採取改變它的性的料理方式，譬如：炒的料理方式 我們吃進食物都是爲了滋養自己，這是其中一個我會評估的面向
有句俗話說： 冬吃蘿蔔夏吃薑，不用醫師開藥方。 「夏天吃薑」是藉由薑的溫辛平衡體內陰陽。 夏天氣候炎熱，容易貪涼飲冷，體內陽氣較虛，吃薑正好可以起到溫補以助陽氣的作用， 進而排除部分臟腑寒氣至體表，以對抗炎熱的氣溫，使身體達到陰陽平衡，通體舒暢。 醃漬過的蘿蔔，其本身的寒涼屬性會改變喔

+

節氣飲食
+
節氣走到春末初夏交接之際，這時節的子薑和桂竹筍很美味。 子薑有春天尾巴鮮嫩的滋味，帶點初夏熱度的微辛辣。 單吃，或與其他食材涼拌、炒或滷，滿口都是春末初夏的味道。 最近如果去傳統市場，會看到許多攤子都擺著一大盆的桂竹筍。 4-5月盛產期是品嚐春季限定「桂竹筍」的最佳時機， 這時期的桂竹筍肉質鮮嫩中帶硬，適合滷、炒、燉湯。 即使腦袋不知道節氣，吃進去的食物自然會提醒你， 我喜歡這種身體與天地萬物同步最直接的方式。

給吳淑婷
採買上你已經有一個很好的分工(市場+全聯） 冷凍是我們常用的保存方式， 不過要知道冷凍用意是延長可食用效期，不是無限期保存， 所以一般建議： *生肉:一個月內 *調味後冷凍:2-3週內 很多人一開始也都會先避開海鮮，這很正常～ 如果你有感覺想嚐試，可以先從鮭魚、蝦仁、蛤仔，這類腥味低處理簡單的開始。有機會的話之後課程也會教「不腥處理」。
給李香潔
香潔對食材的處理已經找到自己的方式， 有在做醃製、分裝，這對備餐很加分， 你已經在做效率型備餐。 有兩個地方想回應： 1.雞腿先川燙再冷凍：這個做法比較適合燉煮用，如果是要煎或其他料理方式，建議生的直接冷凍。 2.蔬菜洗過再冰：這方式雖然方便可立即下鍋但因有水氣容易腐敗，建議蔬菜買回來只洗三天內要煮的量，其他不要洗，用紙巾包起來放塑膠袋冷藏保存會更久。

給亭吟
你有用心在處理食材，這點很重要。 以下有需幫你釐清的地方： 1.煮起來冰冷凍比較新鮮： 剛好相反，生的直接冷凍，通常能保留更多風味；熟的再冷凍，反而風味及口感變差。大部份的肉類都是如此。 2. 蝦子燙起來就冰冷凍，之後再退冰用電鍋加熱： 蝦子螃蟹之類容易腐敗的海鮮，確實先煮熟再冷凍可以保鮮，但食用方式是先放冷藏解凍，再放室溫退冰，並不適合再加熱，再次加熱常會讓風味流失肉質口感改變。 另外，蝦子中間黑黑的一條，有沒有可能是蝦子的腸泥腺，建議在生的時候先去掉再料理會比較好。 3.蔬菜類放進塑膠袋直接放冰箱，常常一下就開始枯萎不新鮮 蔬菜類的保存重點在「不要洗＋減少水氣」，因此如果是容易爛的葉菜類，我會用廚房紙巾包起來放塑膠袋再冰，這樣子保存一週左右，即使葉子有點痿凋，再泡水一下子便會恢復生機。（有時候會用溫水泡，幫助葉子吸水）
